# AMP-FlowRAE 项目简介（一页版）

## 🎯 项目是什么？

**人工智能辅助抗菌肽设计系统** - 使用深度学习技术，根据指定性质自动生成新型抗菌肽序列，用于药物发现和科学研究。

---

## 💡 核心价值

### 解决的问题
- **传统方法**：发现新抗菌肽需要数月到数年，成本高、效率低
- **本系统**：数小时生成候选序列，大幅降低实验成本和时间

### 实际应用
- 为抗耐药菌研究提供新序列
- 加速抗菌药物发现
- 支持精准药物设计

## 🔬 技术路线（简化）

```
1. 数据准备：学习10,491条已知抗菌肽的特征
2. 空间构建：建立"序列设计空间"（类似地图）
3. 可控生成：在空间中根据要求找到合适的位置
4. 序列输出：转换为真实氨基酸序列，评估活性
```

**关键技术：**
- ESM-3蛋白质语言模型（Meta AI）
- Flow Matching生成方法
- 活性预测评分系统

## 🏆 项目亮点

1. ✅ **完整系统**：从数据到序列，端到端解决方案
